      Permet à l'IA du chat et de l'investigation de vérifier elle-même l'état réel de ton infrastructure. Tout est en lecture seule : rien ne peut être démarré, arrêté ou modifié.

      Conteneurs Docker

      Via un proxy du socket Docker qui n'autorise que la lecture (état, santé, redémarrages, logs, consommation). Sentinel ne monte jamais le socket lui-même.

L'adresse http://docker-proxy:2375 est déjà pré-remplie.

L'analyse automatique des alertes n'y a jamais accès.

Lance-le avec docker compose --profile web up -d, puis garde l'adresse proposée.

              2. 
                                
            2. Dans son settings.yml, généralement sous /mnt/user/appdata/searxng/, ajoute json sous search: formats:, à côté de html. Sans ça, SearXNG répond 403.
              3. 
                                
            3. Redémarre SearXNG.
              4.

            Fiches CVE (NVD)
            
                        
                    
            
                    
            Quand une alerte cite un CVE, Sentinel affiche sa fiche officielle : exploitation active (catalogue KEV de la CISA), versions touchées, score. Seul le numéro du CVE part vers NVD. La fiche informe et ne change jamais la gravité : une ligne de log peut citer n'importe quel CVE.
